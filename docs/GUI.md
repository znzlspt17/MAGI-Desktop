# MAGI-Desktop GUI 구현 명세와 작업 계획

기준: 2026-11-15. 사용자가 승인한 전체 구현 계획과 `SPEC.md`를 이어 GUI 코드 구현 및 Windows 빌드를 수행한다. 기존 headless 엔진을 대체하지 않고 네이티브 egui/eframe 클라이언트로 연결한다. 실제 모델 파일과 외부 계정 호출은 이번 검증에 포함하지 않는다. 화면 제어 및 사용자 PC에 창을 띄우는 검사는 수행하지 않는다.

## 설계

Rust GUI는 프로젝트 탐색과 작업 화면을 표시한다. 엔진이 승인과 실행 및 내구 상태의 유일한 소유자다. GUI는 화면의 초안과 편집 상태, 요청의 대상 식별자 및 세대 번호를 갖는다. 엔진에서 받은 승인 해시나 실행 ID를 추정하거나 재생성하지 않는다.

IPC는 제한된 대기열과 병렬 비동기 요청 작업자를 사용한다. 상태 조회와 취소는 긴 검색 또는 MCP 요청 뒤에 직렬 대기하지 않는다. 모든 응답에 원래 요청의 프로젝트/실행 범위와 식별자를 연결한다. 화면 콜백은 파일 I/O, 프로세스 대기, 네트워크 및 저장을 수행하지 않는다. 시작 시 폰트와 엔진 준비도 백그라운드에서 수행한다. 먼저 기존 엔진 연결을 확인하고 필요할 때만 숨김으로 자체 엔진을 시작한다.

현재 사용자 기본 pipe와 하나의 redb를 사용하는 공유 엔진을 유지한다. GUI 종료는 다른 GUI가 연결했을 수 있는 엔진 프로세스를 강제로 종료하지 않는다. 초기 작업 배정에서 제안한 고유 pipe/자식 종료는 공유 데이터베이스 잠금 및 재접속 구조와 충돌하므로 채택하지 않는다. 창 종료 전 작업 취소와 로컬 작업자의 반환 확인은 별도다. 강제 종료로 자식 작업의 상태가 불명확한 과거 기록은 자동 재실행하거나 자원 반환 완료로 표시하지 않고 앱 유지 선택으로 남긴다.

화면은 왼쪽 프로젝트/탐색, 상단 연결 및 실행 상태, 중앙 작업 영역으로 구성한다. MAGI의 요청→인터뷰→명세→평가→승인→구현→검증 순서를 그대로 사용한다. 한국어 라벨, 기존 어두운 작업 공간, 키보드 접근 가능한 표준 egui 위젯을 사용한다. 프로젝트별 편집 내용과 선택을 보존한다. 개발용 API JSON만 표시하는 화면으로 사용자 기능을 대체하지 않는다. 고급 구조화 편집에 JSON 입력을 제공할 경우 설명과 필드/오류를 함께 표시한다.

GUI의 코드 및 프레임 검사는 실제 Windows IME 조합, DPI별 시각 품질, 접근성 트리와 창 조작의 실측을 대신하지 않는다. 화면 검사를 실행하지 않은 항목은 완료 보고에서 별도로 구분한다.

## 구현 순서와 소유권

1. `rust_desktop`: `crates/magi-desktop` 소유. 상태와 비동기 요청 처리의 실패 테스트를 먼저 실행한 뒤 UI와 생명주기를 구현한다. 기존 거대한 main을 책임별 모듈로 나눌 수 있다. 엔진의 승인 정책은 우회하지 않는다.
2. `dev`: `magi-core`의 `ListRuns` 계약 및 engine 조회만 소유. 프로젝트별 1~100개 페이지, 결정적 정렬, 존재하지 않는 프로젝트 거절, 재시작 후 내구 목록과 격리를 Red→Green으로 검사한다. 응답에 비밀이나 대용량 checkpoint를 노출하지 않는다.
3. `pm`: 제출된 PR의 최신 커밋과 계약 대응을 읽기 검토하고 합불과 근거를 게시한다. 기존 엔진의 기능 누락을 UI의 로컬 가짜 동작으로 대체하지 않았는지 확인한다.
4. 조정자: 이 명세와 최종 통합, 독립 workspace 검사 및 결과 기록. GUI 출시 패키징은 `devops`에 맡긴다.

최종 검사는 `cargo fmt --all -- --check`, `cargo test --locked --workspace`, `cargo clippy --locked --workspace --all-targets -- -D warnings` 및 전체 release 빌드다. 현재 폴더의 미커밋 구현을 보존하고 담당자별 격리 브랜치에서 작은 기능별 PR을 `dev`로 제출한다. PM이 해당 커밋을 검토해 합격한 뒤 병합하며 `main` 병합은 사용자가 판단한다. 기존 `D:\Repos\MAGI`는 변경하지 않는다.
